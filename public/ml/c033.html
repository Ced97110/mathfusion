1. The concrete problem

En 1929, le mathématicien américain Lester Hill publie dans l’American Mathematical Monthly une méthode pour chiffrer des messages avec des matrices. Le principe est le suivant. On remplace chaque lettre par un nombre ; prenons ici la convention A = 1, B = 2, C = 3, et ainsi de suite. On groupe les nombres par paires, et chaque paire devient un vecteur. On multiplie ce vecteur par une matrice secrète, la clé. On envoie le résultat. La figure 33.1 montre le trajet complet.

In 1929 the American mathematician Lester Hill published in the American Mathematical Monthly a method for enciphering messages with matrices. The principle is this. Each letter is replaced by a number; here we use the convention A = 1, B = 2, C = 3, and so on. The numbers are grouped in pairs, and each pair becomes a vector. This vector is multiplied by a secret matrix, the key. The result is sent. Figure 33.1 shows the whole journey.

Why must the matrix be square? A 3 × 2 matrix, like 𝐻 in chapter 31, sends the plane into space. A 2 × 3 matrix squashes space onto the plane: two different vectors of space necessarily land on the same point of the plane, and no matrix can separate them afterwards. And the inverse is computed with the determinant, which only exists for square matrices.

Pourquoi ne peut-on pas revenir ? 𝐺′ envoie (𝑥, 𝑦) sur (𝑥 + 𝑦, 𝑥 + 𝑦). Elle ne garde que la somme 𝑥 + 𝑦. Les vecteurs (3, 1), (2, 2) et (4, 0) ont la même somme, 4, donc la même image (4, 4). (𝑥 + 𝑦, 𝑥 + 𝑦). It only keeps the sum 𝑥 + 𝑦. The vectors (3, 1), (2, 2) and (4, 0) have the same sum, 4, so the same image (4, 4). An inverse would have to send (4, 4) back to (3, 1), to (2, 2) and to (4, 0) at once. A matrix sends each vector to a single vector. So no inverse exists.

C’est le sens géométrique de det 𝐺′ = 0 : une dimension est perdue (le plan devient une droite, ou même un point), et l’information perdue ne revient pas. Une telle matrice est dite singulière. Pour la clé de Hill, cela veut dire : une clé de déterminant nul chiffre deux messages différents de la même façon, et la destinataire ne peut pas lire. C’est aussi ce qui arrive aux nombres : 0 est le seul nombre réel sans inverse, car 0 ⋅ 𝑥 = 0 ne vaut jamais 1. Pour les matrices, il n’y a pas qu’une seule matrice sans inverse : toutes celles dont le déterminant est nul.

This is the geometric meaning of det 𝐺′ = 0: a dimension is lost (the plane becomes a line, or even a point), and the lost information does not come back. Such a matrix is called singular. For Hill’s key this means: a key with zero determinant enciphers two different messages in the same way, and the recipient cannot read. The same happens with numbers: 0 is the only real number with no inverse, because 0 ⋅ 𝑥 = 0 is never 1. For matrices there is not just one matrix without an inverse: every matrix whose determinant is zero.
