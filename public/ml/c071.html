In chapter 69 you saw the tool that describes a continuous variable: the density 𝑓 . But the density does not give a probability directly. Its height 𝑓(𝑥) is not a probability. To get a probability you must compute an area under the curve, that is, an integral (chapter 55). For every new threshold, you would have to compute a new integral. It is slow, and it cannot be read off the drawing.

L’idée est donc la suivante : faire ce calcul une fois pour tous les seuils à la fois, et ranger les réponses dans une nouvelle fonction. On lui donne un seuil, elle rend la probabilité d’être en dessous. Cette fonction s’appelle la fonction de répartition.

So the idea is this: do this computation once for all thresholds at the same time, and store the answers in a new function. You give it a threshold, it returns the probability of being below. This function is called the cumulative distribution function.

4. The effects

Premier effet : la probabilité d’un intervalle est une soustraction

La responsable demande : « Quelle est la probabilité que la moyenne générale tombe entre 28,8 et 29,2 ? » L’événement « 𝑋 ≤ 29,2 » contient deux morceaux séparés : « 𝑋 ≤ 28,8 » et « 28,8 < 𝑋 ≤ 29,2 ». Les probabilités de deux morceaux disjoints s’additionnent (chapitre 67). Donc 𝐹 (29,2) = 𝐹 (28,8) + 𝑃 (28,8 < 𝑋 ≤ 29,2), et :

𝑃 (𝑎 < 𝑋 ≤ 𝑏) = 𝐹 (𝑏) − 𝐹 (𝑎).

Avec nos nombres : 𝐹 (29,2) ≈ 0,866 et 𝐹 (28,8) ≈ 0,207, donc 𝑃 (28,8 < 𝑋 ≤ 29,2) = 0,866 − 0,207 = 0,659. Deux moyennes sur trois tombent dans cette fourchette. La figure 71.5 fait le calcul en quatre étapes. Une soustraction a remplacé une intégrale.

First effect: the probability of an interval is a subtraction. The officer asks: “What is the probability that the overall mean lands between 28.8 and 29.2?” The event “𝑋 ≤ 29.2” holds two separate pieces: “𝑋 ≤ 28.8” and “28.8 < 𝑋 ≤ 29.2”. The probabilities of two disjoint pieces add up (chapter 67). So 𝐹 (29.2) = 𝐹 (28.8) + 𝑃 (28.8 < 𝑋 ≤ 29.2), and 𝑃 (𝑎 < 𝑋 ≤ 𝑏) = 𝐹 (𝑏) − 𝐹 (𝑎). With our numbers: 𝐹 (29.2) ≈ 0.866 and 𝐹 (28.8) ≈ 0.207, so 𝑃 (28.8 < 𝑋 ≤ 29.2) = 0.866 − 0.207 = 0.659. Two means out of three fall in this range. Figure 71.5 does the computation in four steps. A subtraction has replaced an integral.

Troisième effet : cinq propriétés que toute fonction de répartition respecte

1. Elle ne descend jamais. Si 𝑎 ≤ 𝑏, alors 𝐹 (𝑎) ≤ 𝐹 (𝑏). Pourquoi ? Toute valeur qui vérifie 𝑋 ≤ 𝑎 vérifie aussi 𝑋 ≤ 𝑏. L’événement « 𝑋 ≤ 𝑎 » est contenu dans l’événement « 𝑋 ≤ 𝑏 ». Un événement contenu dans un autre ne peut pas être plus probable. C’est ce que montraient les barres rouges de la figure 71.2 : 1/15 ≤ 3/15 ≤ 10/15. 2. Elle part de 0 et monte jusqu’à 1. Third effect: five properties that every cumulative distribution function obeys.

1. It never goes down. If 𝑎 ≤ 𝑏 then 𝐹 (𝑎) ≤ 𝐹 (𝑏).
