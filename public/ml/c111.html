1. Le problème concret

1. The concrete problem

Tu écris un code postal à la main sur une enveloppe. Une machine du centre de tri le lit, chiffre par chiffre, sans humain. Chaque chiffre manuscrit est différent : le « 0 » de ta voisine est plus rond que le tien. Comment une machine peut-elle dire « ceci est un 0 » devant un tracé qu’elle n’a jamais vu ? Ce problème, reconnaître une classe à partir de mesures, s’appelle la classification.

You write a postcode by hand on an envelope. A machine at the sorting center reads it, digit by digit, without a human. Every handwritten digit is different: your neighbor’s “0” is rounder than yours. How can a machine say “this is a 0” in front of a stroke it has never seen? This problem, recognizing a class from measurements, is called classification.

L’équipe imaginée du Centre du diamant (chapitre 110) rencontre ce problème. La caméra a filmé le clavier du garage pendant plusieurs jours. Mais l’objectif était sale : les chiffres tapés par les gardes sont flous. La collègue qui traitait les images a dû partir en hâte. Elle laisse une note et trois tableaux. La figure 111.1 montre ces trois tableaux et les quatre mesures qu’elle a prises sur chaque chiffre.

5. La finalité

5. Where it leads

Le classifieur naïf est un premier modèle d’apprentissage automatique complet : il apprend des paramètres sur des données étiquetées, puis il décide pour des données nouvelles. Il est aussi un point de départ.

The naive classifier is a first complete machine learning model: it learns parameters from labeled data, then it decides for new data. It is also a starting point.
