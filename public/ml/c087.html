Lis la figure comme une recette. Le long d’un chemin, tu multiplies les dérivées des flèches. Puis tu additionnes les chemins. Pourquoi multiplier ? Parce que le long d’un chemin, l’effet se transmet. Si 𝑧 avance d’un petit pas ℎ, 𝑥 avance de 2ℎ. Ce 2ℎ fait avancer 𝑤 de 6 × 2ℎ = 12ℎ.

Read the figure as a recipe. Along a path you multiply the derivatives of the arrows. Then you add the paths. Why multiply? Because along a path the effect is passed on. If 𝑧 moves by a small step ℎ, 𝑥 moves by 2ℎ. That 2ℎ moves 𝑤 by 6 × 2ℎ = 12ℎ.

Pourquoi additionner ? Parce que 𝑤 = 3𝑥2 + 2𝑦 est une somme de deux morceaux. Le morceau 3𝑥2 change avec 𝑥, le morceau 2𝑦 change avec 𝑦. Quand 𝑧 avance de ℎ, les deux morceaux changent en même temps : 12ℎ pour le premier, 4ℎ pour le second. Leur somme change de 16ℎ.

Why add? Because 𝑤 = 3𝑥2 + 2𝑦 is a sum of two pieces. The piece 3𝑥2 changes with 𝑥, the piece 2𝑦 changes with 𝑦. When 𝑧 moves by ℎ, both pieces change at the same time: 12ℎ for the first, 4ℎ for the second. Their sum changes by 16ℎ.
