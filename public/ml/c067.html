Pourquoi ces trois axiomes ? Chacun est une propriété du comptage de la figure 67.2. Le premier interdit une probabilité négative, parce qu’une case ne peut pas contenir −2 points. Il interdit aussi une probabilité au-dessus de 1, parce que la case ne contient jamais plus de 15 points. Le deuxième dit que tout point est quelque part sur la droite : 15/15 = 1. Le troisième dit que, si deux cases ne partagent aucun point, compter les deux revient à additionner les deux comptes : 0 + 1 = 1 pour ]10 ; 15] et ]35 ; 40].

Why these three axioms? Each is a property of the counting in figure 67.2. The first forbids a negative probability, because a box cannot hold −2 dots. It also forbids a probability above 1, because a box never holds more than 15 dots. The second says that every dot is somewhere on the line: 15/15 = 1. The third says that if two boxes share no dot, counting both means adding the two counts: 0 + 1 = 1 for ]10; 15] and ]35; 40].

Variable discrète, variable continue

Toutes les variables aléatoires ne se ressemblent pas. Le nombre de gardes en service se compte : 2, 3 ou 4. Le nombre d’alarmes déclenchées aussi. Une telle variable est discrète : ses valeurs se numérotent une par une, et chacune a sa propre probabilité, par exemple 𝑃 (𝑋 = 3). Discrète ne veut pas dire « en nombre fini ». Le nombre d’essais pour ouvrir un coffre peut valoir 1, 2, 3, et ainsi de suite sans fin. On peut pourtant numéroter ces valeurs.

Discrete variable, continuous variable. Not all random variables look alike. The number of guards on duty is counted: 2, 3 or 4. So is the number of alarms triggered. Such a variable is discrete: its values can be numbered one by one, and each has its own probability, for example 𝑃 (𝑋 = 3). Discrete does not mean “finitely many”. The number of attempts needed to open a safe can be 1, 2, 3, and so on without end. These values can still be numbered.

La durée d’une coupure est différente. Elle peut valoir 15,5 minutes, ou 16,75, ou n’importe quel nombre entre les deux. Une telle variable est continue.
