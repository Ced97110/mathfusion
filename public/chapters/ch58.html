Chapitre 58

Modules libres et matrices, sommes directes

1. Le problème concret

Vous tenez une petite épicerie. Vous vendez deux produits seulement : du riz et des lentilles. Un client repart avec 2 kg de riz et 1 kg de lentilles. Un autre avec 5 kg de riz et 4 kg de lentilles. Comment noter une vente ? Par deux nombres, dans un ordre fixé : d’abord le riz, puis les lentilles. La première vente s’écrit (2, 1), la seconde (5, 4). Vous pouvez additionner deux ventes : (2, 1) + (5, 4) = (7, 5). Vous pouvez multiplier une vente par un entier : trois fois la première, c’est (6, 3). Vous reconnaissez la structure du chapitre 57 : les couples d’entiers, avec l’addition et la multiplication par un entier, forment un module sur l’anneau ℤ. Ce module s’appelle ℤ(2). Posez-vous maintenant la question de l’inventaire. Vous recevez une livraison, un sac à la fois. Il y a deux sacs types : le sac « un kilo de riz », noté 𝑒1 = (1, 0), et le sac « un kilo de lentilles », noté 𝑒2 = (0, 1). Toute vente s’écrit avec ces deux sacs : (5, 4) = 5𝑒1 + 4𝑒2. Et elle s’écrit d’une seule façon : si (5, 4) = 𝑎𝑒1 + 𝑏𝑒2, alors 𝑎 = 5 et 𝑏 = 4, il n’y a pas d’autre choix. C’est ce fait qui fait tout le chapitre. Deux objets 𝑒1, 𝑒2 suffisent pour écrire tous les éléments du module, et chaque élément s’écrit d’une seule manière. On dira que (𝑒1, 𝑒2) est une base. Quand un module a une base, il est dit libre. Vous allez me dire : « Tout module n’a-t-il pas une base ? » Non. Prenez l’horloge à deux heures du chapitre 47, le module ℤ/2ℤ = {0, 1} sur ℤ. Son seul élément non nul est 1. Mais 2 ⋅ 1 = 0 et aussi 0 ⋅ 1 = 0 : l’élément 0 s’écrit de deux façons différentes à partir de 1. L’écriture n’est pas unique. Ce module n’a pas de base. Il n’est pas libre. Vous verrez à la partie 4 pourquoi ce cas limite est important. Deuxième question concrète. Un fournisseur ne vend pas au kilo. Il vend deux lots : le lot 𝑓1 = 2 kg de riz et 1 kg de lentilles, soit (2, 1), et le lot 𝑓2 = 1 kg de riz et 1 kg de lentilles, soit (1, 1). Pouvez-vous obtenir n’importe quel stock entier avec ces lots, sans en ouvrir aucun ? Oui : 𝑒1 = 𝑓1 − 𝑓2 et 𝑒2 = 2𝑓2 − 𝑓1. Vérifiez : (2, 1) − (1, 1) = (1, 0) et 2(1, 1) − (2, 1) = (0, 1). Donc (𝑓1, 𝑓2) est une autre base du même module. Passer d’une base à l’autre, c’est un changement de base. Il se décrit par un tableau de quatre nombres : une matrice. Troisième question. Un transporteur applique une transformation à chaque stock : il remplace le sac 𝑒1 par (2, 1) et le sac 𝑒2 par (1, 3). Que devient le stock (5, 4) ? Il suffit de connaître les images des deux sacs de base, et la transformation est entièrement connue. Là encore, quatre nombres suffisent : une matrice. Enfin, la question de la découpe. Le stock (5, 4) est la somme d’un stock de riz pur, (5, 0), et d’un stock de lentilles pur, (0, 4). Les stocks de riz pur forment un sous-module 𝑀1, les stocks de lentilles pur un sous-module 𝑀2. Tout élément est somme d’un élément de 𝑀1 et d’un élément de 𝑀2, d’une seule façon. On dira que le module est la somme directe de 𝑀1 et 𝑀2, et on écrira 𝑀 = 𝑀1 ⊕ 𝑀2.

C’est cela, une base : deux directions qui ne sont pas alignées, et à partir desquelles chaque point du plan reçoit un unique couple de coordonnées. Vous allez me dire : « Mais au chapitre 19, les coordonnées d’un point se lisaient sur les axes horizontal et vertical. » Oui. Les axes du chapitre 19 correspondent à la base (𝑒1, 𝑒2) avec 𝑒1 = (1, 0) et 𝑒2 = (0, 1). Dans cette base, 𝑤 a pour coordonnées (5, 4). Dans la base (𝑢, 𝑣), le même point 𝑤 a pour coordonnées (2, 1). Le point ne change pas ; ce sont les nombres qui le décrivent qui changent. Retenez cette distinction : elle est la source du changement de base.

Le module 𝑅(𝑛)

Soit 𝑅 un anneau (chapitre 51). Soit 𝑛 un entier naturel. On note 𝑅(𝑛) l’ensemble des listes de 𝑛 éléments de 𝑅, écrites (𝑥1, 𝑥2, … , 𝑥𝑛), avec 𝑥𝑖 ∈ 𝑅. Trois opérations le rendent module sur 𝑅 :

0 = (0, 0, … , 0)

La première ligne : on additionne case par case. La deuxième : l’élément neutre est la liste de zéros. La troisième : multiplier une liste par 𝑎 ∈ 𝑅, c’est multiplier chaque case par 𝑎. Les quatre conditions de module du chapitre 57 se vérifient case par case, parce que chaque case vit dans 𝑅. Pour 𝑛 = 1, 𝑅(1) est 𝑅 lui-même, vu comme module sur lui-même. Pour 𝑛 = 0, la seule liste est la liste vide : 𝑅(0) est le module nul {0}. Gardez ce cas en tête.

Théorème (base et 𝑅(𝑛)). Si 𝑀 a une base de 𝑛 éléments, alors 𝑀 ≅ 𝑅(𝑛). La cause est simple. Définissez 𝜇 ∶ 𝑅(𝑛) → 𝑀 par 𝜇(𝑥1, … , 𝑥𝑛) = ∑ 𝑥𝑖𝑢𝑖. C’est un homomorphisme de modules (chapitre 57) : il respecte l’addition et la multiplication par 𝑎, parce que ces opérations se font case par case des deux côtés. Il est surjectif parce que les 𝑢𝑖 engendrent 𝑀 . Son noyau est nul parce que ∑ 𝑥𝑖𝑢𝑖 = 0 force tous les 𝑥𝑖 à être nuls (indépendance). Un homomorphisme bijectif est un isomorphisme (chapitre 48). Donc un module libre à base de 𝑛 éléments n’est rien d’autre, à renommage près, que 𝑅(𝑛). Le même raisonnement donne une propriété plus forte, que vous réutiliserez sans cesse : si (𝑒1, … , 𝑒𝑛) est une base de 𝑀 et si (𝑣1, … , 𝑣𝑛) est une liste quelconque d’éléments d’un module 𝑁 , il existe un unique homomorphisme 𝜂 ∶ 𝑀 → 𝑁 tel que 𝜂(𝑒𝑖) = 𝑣𝑖 pour tout 𝑖. Il est donné par 𝜂(∑ 𝑥𝑖𝑒𝑖) = ∑ 𝑥𝑖𝑣𝑖. Autrement dit, pour connaître un homomorphisme au départ d’un module libre, il suffit de connaître les images des éléments de la base. C’est exactement ce que faisait le transporteur de la partie 1. Théorème 3.4 (invariance du rang). Si 𝑅 est commutatif et si 𝑅(𝑚) ≅ 𝑅(𝑛), alors 𝑚 = 𝑛. Dit autrement : sur un anneau commutatif, toutes les bases d’un module libre ont le même nombre d’éléments. Ce nombre s’appelle le rang du module. Espaces vectoriels : la définition directe

Au chapitre 57, vous avez lu qu’un module sur un corps s’appelle un espace vectoriel. Le manuel de Judson fait le chemin inverse : il définit l’espace vectoriel directement, sans passer par les modules. C’est la définition que vous trouverez dans la plupart des cours. La voici. Un rappel d’abord. Un corps 𝐹 (chapitre 51) est un anneau commutatif où tout élément non nul a un inverse pour la multiplication. ℚ, ℝ, ℂ sont des corps, et ℤ/𝑝ℤ aussi quand 𝑝 est premier. ℤ n’est pas un corps : 2 n’a pas d’inverse entier. Définition. Un espace vectoriel 𝑉 sur un corps 𝐹 est un groupe abélien (𝑉 , +) (chapitre 44) muni d’un produit par un scalaire. Ce produit associe, à tout 𝛼 ∈ 𝐹 et à tout 𝑣 ∈ 𝑉 , un élément 𝛼𝑣 de 𝑉 . Il vérifie quatre règles, pour tous 𝛼, 𝛽 ∈ 𝐹 et tous 𝑢, 𝑣 ∈ 𝑉 :

𝛼(𝛽𝑣) = (𝛼𝛽)𝑣

(𝛼 + 𝛽)𝑣 = 𝛼𝑣 + 𝛽𝑣

𝛼(𝑢 + 𝑣) = 𝛼𝑢 + 𝛼𝑣

1𝑣 = 𝑣

Ce sont mot pour mot les quatre règles de module du chapitre 57, avec 𝑅 = 𝐹 . Les éléments de 𝑉 s’appellent des vecteurs. Les éléments de 𝐹 s’appellent des scalaires. Les lettres grecques 𝛼 (alpha), 𝛽 (bêta), 𝛾 (gamma), 𝛿 (delta) désignent des scalaires ; les lettres latines 𝑢, 𝑣, 𝑤 désignent des vecteurs. Il y a deux zéros : on écrit 0 pour le scalaire nul et 0, en gras, pour le vecteur nul.

Vous allez me dire : « Et le produit de deux vecteurs ? » Il n’existe pas en général. Un espace vectoriel sait additionner deux vecteurs et multiplier un vecteur par un scalaire. Rien de plus. En un point 𝑥, ((𝛼 + 𝛽)𝑓)(𝑥) = (𝛼 + 𝛽)𝑓(𝑥) = 𝛼𝑓(𝑥) + 𝛽𝑓(𝑥). C’est la distributivité des nombres réels (chapitre 3), appliquée au nombre 𝑓(𝑥). Quatre règles de calcul (Judson, proposition 20.5). Indépendance linéaire : le test

Définition. Une famille (𝑣1, … , 𝑣𝑛) est linéaire- ment dépendante, ou liée, s’il existe des scalaires 𝛼1, … , 𝛼𝑛, pas tous nuls, tels que

𝛼1𝑣1 + 𝛼2𝑣2 + ⋯ + 𝛼𝑛𝑣𝑛 = 0

Sinon, la famille est linéairement indépen- dante, ou libre. La combinaison où tous les 𝛼𝑖 valent 0 donne toujours 0. On l’appelle la combinaison tri- viale. Le test d’indépendance se dit donc en une phrase : une famille est indépendante quand la seule combinaison nulle est la combinai- son triviale. En pratique : écrivez 𝛼1𝑣1 + ⋯ + 𝛼𝑛𝑣𝑛 = 0, traduisez cette égalité en un système d’équations (chapitre 24), et résolvez. Si la seule solution est 𝛼1 = ⋯ = 𝛼𝑛 = 0, la famille est indépendante. S’il existe une autre solution, elle est liée. Exemple complet. Prenez 𝑢 = (3, 1) et 𝑣 = (1, 2) dans ℝ2. L’égalité 𝛼𝑢 + 𝛽𝑣 = 0 s’écrit (3𝛼 + 𝛽, 𝛼 + 2𝛽) = (0, 0). La première équation donne 𝛽 = −3𝛼. La seconde devient 𝛼 − 6𝛼 = 0, donc −5𝛼 = 0, donc 𝛼 = 0, puis 𝛽 = 0. Seule la combinaison triviale : (𝑢, 𝑣) est indépendante. Ajoutez 𝑤 = (−1, 3). L’égalité 𝛼𝑢 + 𝛽𝑣 + 𝛾𝑤 = 0 donne deux équations pour trois inconnues : 3𝛼 + 𝛽 − 𝛾 = 0 et 𝛼 + 2𝛽 + 3𝛾 = 0. Choisissez 𝛾 = −1. Il reste 3𝛼 + 𝛽 = −1 et 𝛼 + 2𝛽 = 3. La première donne 𝛽 = −1 − 3𝛼 ; la seconde devient 𝛼 − 2 − 6𝛼 = 3, donc 𝛼 = −1, puis 𝛽 = 2. Vérifiez : −(3, 1) + 2(1, 2) − (−1, 3) = (−3 + 2 + 1, −1 + 4 − 3) = (0, 0). Les coefficients (−1, 2, −1) ne sont pas tous nuls : (𝑢, 𝑣, 𝑤) est liée.

5. Où cela mène (finalité)

Le chapitre 59 prend un homomorphisme entre modules libres sur un anneau principal (ℤ, ou 𝐾[𝑥]), donc une matrice, et cherche les bases de départ et d’arrivée qui la rendent diagonale. Il en déduit que tout sous-module de ℤ(𝑛) est libre, puis le théorème de structure : tout module de type fini sur un anneau principal est une somme directe de modules cycliques. Sans la notion de base, pas de matrice ; sans la somme directe, pas d’énoncé. Le chapitre 60 applique ce théorème aux groupes abéliens finis et aux transformations linéaires : la torsion, rencontrée ici comme obstacle, y devient l’objet central, et la relation 𝐴′ = 𝑃 −1𝐴𝑃 y conduit aux formes normales d’un endomorphisme. Le chapitre 71 introduit les formes bilinéaires. Une forme bilinéaire sur un module libre est, elle aussi, un tableau de nombres : 𝑏𝑖𝑗 = 𝑏(𝑒𝑖, 𝑒𝑗).
